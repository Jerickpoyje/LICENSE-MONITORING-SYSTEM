# Monitoring License React Frontend

This is a pure React/Vite implementation of the license monitoring app.

## Setup
1. Open a terminal in `react-frontend`
2. Run `npm install`
3. Run `npm run dev`

## Behavior
- The app stores data locally using `localStorage`.
- No PHP backend is required for the React app itself.
- Sample users and license records are seeded automatically on first run.

## Notes
- Login, registration, user management, and license CRUD are implemented in JavaScript.
- Data persists across browser sessions in `localStorage`.
